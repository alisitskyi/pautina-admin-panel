# Повний аудит адмін-панелі Pautina Rooms (Квест-кімнати)

> Згенеровано на основі реверс-інжинірингу сесії адміністратора та аналізу коду оригінальної панелі (`https://www.pautina-rooms.com/admin/times`).

---

## 1. Архітектура та стек оригінальної системи

* **Бекенд-фреймворк:** **PHP Yii2 Framework** (контролери `TimesController`, `BookingController`, `SiteController`, `DefaultController`).
* **Фронтенд:** Bootstrap 3 (2016 р.), jQuery, PJAX (`yii.activeForm.js`, `jquery.pjax.js`), Dropzone.js, FontAwesome 4.6.
* **Підхід до рендерингу:** Server-Side Rendering (SSR) з HTML-фрагментами, які повертаються через AJAX і вставляються в модальне вікно `#BMD`.
* **Захист:** Yii2 CSRF токени (`_csrf` cookie + hidden inputs).

### 2.2. Сітка розкладу сеансів (`Timeline` / `/admin/times`)
* **Структура сітки:**
  * Кожна кімната має розклад на ~20 днів уперед (`19.10.2026`, `20.10.2026`, ...).
  * Кожен сеанс (`div.cell.reserv-item`) містить:
    * `timeline_id` (наприклад, `732442`)
    * `time` — час початку (наприклад `10:30`, `12:00`, `13:30`, `15:00`, `16:30`, `18:00`, `19:30`, `21:00`, `22:30`)
    * `price` — динамічна ціна сеансу в гривнях (ранок/день: 1600 грн, вечір: 1800-2200 грн)
    * `status` — клас `free` (вільний) або зайнятий/заброньований.
  * **Дії в інтерфейсі:**
    * Клік на вільний слот: `newBooking(timelineID)`
    * Клік на зайнятий слот: `editBooking(bookingID)`

### 2.3. Модель бронювання (`Booking` / `/admin/booking`)
Форма створення/редагування броні містить такі поля:

```typescript
interface Booking {
  id?: number;
  timeline_id: number;          // ID конкретного слоту часу
  name: string;                 // Ім'я клієнта (обов'язкове)
  phone: string;                // Номер телефону клієнта (обов'язкове)
  email?: string;               // Email клієнта
  user_comment?: string;        // Коментар, залишений клієнтом на сайті
  admin_comment?: string;       // Внутрішній коментар оператора
  client_confirm: boolean;      // 0 = не підтверджено, 1 = підтверджено клієнтом
  game_status: GameStatus;      // Статус гри
  service: number;              // Сервісні прапорці / дод. послуги
  created_at?: string;          // Дата створення бронювання
}

enum GameStatus {
  NOT_PLAYED = 0,               // "Гра не відбулася" (скасовано)
  COMPLETED = 1,                // "Гра відбулася"
  UPCOMING = 2,                 // "Буде грати" (активна бронь)
  SERVICE_HOLD = 3              // "Сервісна бронь" (технічна пауза / ремонт)
}
```

* **Перенесення броні (`#transfer-checkbox`):**
  * Дозволяє оператору перенести клієнта на інший час/день або в іншу кімнату через API:
  `POST /admin/times/gettimes?time={time}&room={roomId}`.

## 3. Слабкі місця поточної адмінки (Чому варто зробити кращу)

1. **Застарілий інтерфейс (2016 рік):** Старий Bootstrap 3, темна важка кольорова гама, незручно працювати годинами операторам.
2. **Погана адаптивність під телефони:** Якщо адміністратор або власник відкриває розклад з мобільного, сітка ламається або вимагає постійного горизонтального скролу.
3. **Зайві AJAX-запити:** При відкритті будь-якого вікна броні відправляється 2 окремих `POST` запити за сирим HTML, що сповільнює роботу при поганому інтернет-зв'язку.
4. **Немає швидкого пошуку клієнта:** Щоб знайти бронь за номером телефону клієнта, доводиться відкривати сторінку списку та чекати перезавантаження PJAX.
5. **Відсутність Real-Time:** Якщо два оператори одночасно приймають дзвінки, вони не бачать у реальному часі, що слот щойно зайняли.

## 4. План реалізації нової сучасної адмін-панелі

### Стек технологій:
* **Фронтенд:** Next.js 15 (React 19) + Tailwind CSS + Shadcn UI.
* **Швидкі таблиці та календар:** TanStack Table v8 + FullCalendar / Custom Responsive Matrix.
* **Бекенд / База даних:** Node.js (Next.js Server Actions / API Routes) + Prisma ORM (SQLite / PostgreSQL).
* **Стейт та валідація:** Zod + React Hook Form + SWR / React Query.

### Ключові покращення в новій версії:
1. **Інтерактивна сітка розкладу з перемиканням режимів:**
   - Режим "День" (усі кімнати на один день — дуже зручно для адміна на зміні).
   - Режим "Кімната" (одна кімната на 2-3 тижні вперед).
2. **Швидкий миттєвий пошук (Ctrl+K):** пошук броні за прізвищем, ім'ям або останніми цифрами телефону за 50 мс.
3. **Зручне створення броні в 1 клік:** модалка з автоформатуванням номера телефону (`+380...`), підрахунком суми та швидким перемиканням статусів.
4. **Сучасна світла/темна тема:** адаптована для планшетів та смартфонів.
